Unit and integration tests for the avatar pipeline.

- `test_audio_encoder.py` — HuBERT encoder tests
- `test_motion_translator.py` — Motion translator tests
- `test_tts_bridge.py` — TTS-to-audio-driver bridge tests
- `test_virtual_camera.py` — Virtual camera output tests
- `test_integration.py` — End-to-end pipeline integration tests
