## Contracts and ownership

[Contracts](../src/talkinghead_v2/contracts/__init__.py) define immutable `GenerationKey`/`Envelope`, `TextSegment`, mono floating-point `AudioChunk`, `AudioEOF`, `Discontinuity`, epoch start/cancel events, explicit `ProviderCapabilities`, and versioned rig/motion identity. Envelopes carry session, turn, epoch, sequence and trace identity. Integer positions/rates/cursors reject booleans, negative values and values beyond signed 64-bit range. Invalid PCM, schema versions, coefficient widths, quaternions and rig hashes fail explicitly. Provider capabilities declare incremental text/audio behavior separately; no neural backend is qualified by these contracts.

[SampleLedger](../src/talkinghead_v2/audio/clock.py) enforces contiguous half-open sample ranges and strictly increasing event sequence numbers in one generation/rate. Empty chunks advance sequence but not samples. Native sample 0 begins each generation; duplicate/reordered callbacks, gaps, overlaps, wrong sessions/turns/epochs or rate changes fail before mutating the ledger. Sequence numbers may skip; sample ranges may not. EOF closes once. Queue-empty never closes a generation.

[GenerationSession](../src/talkinghead_v2/session/epochs.py) serializes native callbacks on one asyncio owner loop. Producers must await `push`/`finish` and marshal thread callbacks to that loop; callers must not create an unbounded set of waiting tasks. It bounds each native callback to one second and splits output to fit the configured queue. Output segment IDs follow source sample spans through resampler lookahead, including EOF tails. Invalid input ordering leaves the ledger intact; failures after accepting input, or cancellation of a blocked producer task, explicitly cancel the generation instead of resuming after lost speech.

Cancellation advances the epoch fence, clears queued events and discards filter history. A blocked old producer wakes and returns false; a blocked old consumer raises `EpochCancelled`. Late audio/EOF callbacks fail at ingestion. The sink checks identity again, including for work dequeued before cancellation. A restart has a newer key and isolated sample/filter state. `CancelAck` reports discarded queue items/samples and the last **synthetically scheduled** sample with its rate; its scope is explicitly `synthetic_in_process`. It acknowledges neither real provider compute nor hardware/browser buffers.

A discontinuity validates its exact boundary, terminates that epoch through the same cancellation fence, and requires an explicit restart. It does not fill missing speech with zeros, bridge filter history or interpolate across an unknown gap. Mid-epoch rate changes are rejected. This conservative reference policy can be extended only with explicit gap/mapping semantics.

## Resampling and queue semantics

[RationalResampler](../src/talkinghead_v2/audio/resample.py) is a pure-Python centered windowed-sinc FIR reference with rational phase, normalized phase kernels, retained history and a low-pass cutoff for downsampling. Equal rates pass through exactly. The default radius is 32 input samples; non-equal-rate streaming waits for that right context. Output timestamp `j` maps to native position `j * input_rate / output_rate`; it carries no completion-time shift. This compensates the centered filter in the logical timestamp mapping while retaining its actual availability delay. Real-time throughput and neural-output quality are unmeasured.

For `N` valid native frames, EOF emits exactly `ceil(N * output_rate / input_rate)` output timestamps, all strictly before the exact native duration. Internal zero extension flushes the filter but emits no extra context-only frames. `AudioEOF.valid_end_sample` records the exact rational boundary in output units; the final represented sample interval can be fractional. The integer output frame count must not be mistaken for an exactly equal source duration. Repeated resampler `finish()` is empty, while repeated pipeline EOF is rejected. Cancellation clears state and never flushes its tail. Fractional **native** padding is rejected by this adapter; a future provider must trim/declare valid native PCM explicitly.

The filter retains at most two radii of input history after each push; phase kernels are cached for a fixed rate pair. Its transient work is bounded by the admitted native callback. [MediaQueue](../src/talkinghead_v2/audio/queue.py) bounds both item count and exact media duration, including item-count protection for zero-length chunks and EOF. Full queues backpressure producers without eviction. Oversized chunks fail explicitly. Reset cannot reactivate a cancelled key, use another session, or silently clear audio under the same epoch.

[Motion interpolation](../src/talkinghead_v2/audio/motion.py) evaluates integer audio positions, linearly blends coefficients/translation and uses quaternion SLERP. It refuses extrapolation, validity gaps, mismatched rates, sessions/turns/epochs, coefficient ordering, basis/topology hashes and pose conventions. Equal vector dimensions never authorize compatibility.

[SyntheticSink](../src/talkinghead_v2/session/synthetic.py) records exact rational nanosecond PTS in the named `synthetic_audio_schedule` clock. Its session cursor stays monotonic across epochs although generation sample cursors restart. This is a scheduling test, not RTP transport, wall-clock pacing, drift estimation or actual audio presentation. The recorder intentionally retains the small fixture in memory; it is not a bounded production output sink.
